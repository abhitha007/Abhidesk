# AbhiDesk Web
Existing Firebase configuration retained verbatim. No build step. Run `python -m http.server 5500` in this folder and open http://localhost:5500. For two devices deploy to HTTPS (Firebase Hosting or another static host). Use different browser profiles/devices to obtain different addresses. Enter the other address, accept on the sharing device, choose a screen, and test chat, pointer permission, fullscreen and disconnect.

This is a prototype, not a production-secure remote access service. Existing Firestore rules must permit the signaling operations on invites, calls and candidate subcollections; do not deploy public read/write rules. Authentication, participant-scoped authorization, abuse prevention, expiration/cleanup and a credentialed TURN service must be implemented before public release. STUN-only connections may fail across restrictive networks. Browser pointer is a visual overlay in the local preview only, not OS input. No unattended access, desktop control, file transfer or system audio. Firebase live integration and cross-device behavior have not been tested here. Session history is local only. No changes to your Firebase console were made.
