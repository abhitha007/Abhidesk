# AbhiDesk
1. Run from this folder: `npx serve .`  (screen share needs localhost or https; opening index.html by double-click will not work)
2. Open on two devices. Person A pastes Person B's ID and clicks Invite. B accepts and picks a screen. A sees it.
3. A clicks "Request Control"; B clicks Allow. For real mouse/keyboard control, B runs agent/agent.js (instructions at top of that file).
4. Errors show in the status line under the buttons.
